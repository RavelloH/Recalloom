# V5：响应式编辑器交互（2026-11-10）

## 交互职责
- 格式工具栏处理**修饰、转换与状态切换**；斜杠菜单和触控端「+」仅负责**新建与插入**。
- 正文是标题菜单的「重置为正文」状态，而不是斜杠菜单中的独立块。标题 1–6 级、项目/编号/待办列表、引用与对齐均为格式工具；再次选择当前状态可复位。
- RMD mark 对外叫「高亮」，使用黄色 H；RMD highlight 对外叫「荧光笔」，属于手绘标记；语法本身保持不变。
- 「更多」包含原有行内组件、上标、下标和「注释」（旧称弱化注释）。行内代码、行内公式、链接为常用直接按钮。

## 响应式交互
- 通过 CSS 媒体能力判断：hover: hover 且 pointer: fine 才显示桌面 BubbleMenu、右键菜单和专用拖拽把手。**不以 720px 判断输入设备**：Pad 外接键鼠可以自动切换桌面交互，触控 Pad 保留原生选区菜单。
- 内容宽度的 720px 断点只处理排版和移动 Drawer。
- 触控端始终提供顶部工具栏，44px 按钮、水平滚动，添加「+」入口打开完整插入菜单；在显式 RMD 块内部选中时追加当前块编辑／更多操作。
- 桌面块把手为竖排的拖动、编辑、更多三个控件；自绘拖拽预览期间隐藏 ProseMirror 原生 drop cursor，禁用富链接卡的节点级原生 draggable 以免双重幻影。

## 右键菜单
- 普通文字使用真正点中的选区，不泄漏上个段落的选区；目标是图片/表格/代码时优先提供对象操作。
- 链接：打开、复制、编辑和移除；图片：下载、复制；表格：增删行列、合并与拆分；代码块：复制代码、语言选择。
- 粘贴尽可能调用 Clipboard API 并交给 ProseMirror 自有粘贴处理，权限不允许时提供 Ctrl+V／⌘V 提示；Shift+右键或菜单已打开时再次右键允许使用原生浏览器菜单。
- 空白位置右键新增「插入」，打开与斜杠快捷键共用的插入选择器。
- Astryx ContextMenu 的 section 列表会把嵌套项处理成叶子。代码语言子菜单提升为菜单根条目，才能真正展开。

## 动画与验收
- Drawer 支持进入和退出动画（退出后再卸载）；桌面右侧滑入，手机底部滑入。Tooltip 与 Popover 使用短淡入；保留浮动定位的 transform。
- 无障碍：按钮语义标签、菜单键盘导航、prefers-reduced-motion 保护。
- 测试隔离目录 E:/Recalloom-editor-v5，分支 feat/editor-responsive-v5；未改生产数据、未更改其它 Agent 工作树。
- pnpm check / pnpm build:web / pnpm test 已通过，其中单元测试 287/287，35 套。
- Edge 桌面以及 Pad 1024px、iPhone 390px 触控模拟的 V5 关键 E2E 通过；真实链路验证链接更新/移除、表格行列增删、代码语言切换、图片菜单、实际剪贴板粘贴与 Shift+右键。桌面标题、列表、引用、对齐状态二次点击复位；Tooltip 动画与减少动态效果均通过浏览器验收。
- 2026-11-10 最终测试：pnpm check、pnpm build:web、pnpm test 287/287（35 套）、单次连续 pnpm test:editor 等价的 28/28 Edge 浏览器 E2E（187.1 秒，单 Worker 和隔离 D1）全部通过；临时数据库和服务由测试运行器自动清理。
- Drawer 在退出动画中快速切换另一个块的旧关闭定时器竞态已通过“LinkCard → Wiki Embed”连续编辑测试验证修复；保留当前块移动、重复、撤销、嵌套子块合法性及 RMD 源码回写验证。
- Edge 模拟不能代表真机 iOS Safari、输入法、触控手势；跨域图片复制与下载受到 CORS 和浏览器剪贴板权限限制。
