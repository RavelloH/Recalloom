## 八项修复与技术原因

1. **右键位置**：Astryx ContextMenu 的锚点/祖先会因定位层和入场动画产生嵌套坐标偏移。仅对此菜单禁用外层变换，并在首次约 480ms 内基于实际视口矩形校正其浮层位置和窗口边界，之后不再持续读取布局。E2E 以鼠标点击的 X/Y 断言位置，而非只检查宽度。
2. **选区格式栏**：保留加粗/斜体/下划线/删除线/语义 Mark 等常用动作；公开链接、行内公式、弱化注释等直接命令；手绘、行内组件、更多格式改为纯图标加下拉箭头的三个分类按钮（分类约 44px，其它图标约 30px）。桌面/移动端的命令选区快照恢复继续沿用；右键菜单对应按剪贴板、常用格式、更多格式二级菜单、手绘、行内组件、历史分层，子菜单支持悬停和点击。
3. **块把手悬停**：把手在 `body` Portal 中，正文和把手之间有 9px 间隔，之前离开正文立即清除 Hover。现在检查整个“块—沟槽—把手”的连续指针通道，只在真正走出外侧通道后隐藏，保留块边界之外的放置原则，不把把手移回正文流。
4. **右侧 Drawer 预览**：Portal 脱离 `.record-main` 导致主题文档排版和 RMD 颜色 CSS 丢失。为预览容器重新引入 `record-main` 样式作用域，单独调整预览区字号、行高、内距、宽度和滚动上限。实测 Warning Callout CSS 色值 `#916013` 且预览实际宽度未超过容器。
5. **手写块文字居中**：旧的固定像素纵向平移在不同字体下可能反向偏移。改为测量 `Range.getBoundingClientRect()` 的实际文字范围中心与块视觉边框中心的差值，做最多 4px 的受控修正；只对非 KaTeX 的普通块手绘方框/圈选/括号应用。Edge E2E 示例中文字与方框纵向中心差 `0.234375px`，上下留白约 `8.0px / 8.47px`，相较此前约 `10.42px / 6.05px`。
6. **右键上下文隔离**：必须在实际选中文字的 glyph 矩形里右键才显示文字操作，直接右键另一个 RMD 块则仅显示块操作。为防止右键 `pointerdown` 导致原生或 PM 选区提前塌缩，使用当前 PM 选区、原生选区、最近一次有效且同文档版本的选区三级候选，命中后恢复原始范围；新增“先选中文字，再右键另一个块”的回归。
7. **Callout 原位标题**：继续在原显示 `span` 直接 `contentEditable`，不出现输入框、尺寸跳动、图标切换或焦点高亮背景。保留不可编辑但无视觉样式的 NodeView 隔离包装，避免 ProseMirror 将其输入误认作正文内容并重置。浏览器断言 DOM 节点未替换、`input` 数为零、Enter 提交、样式无额外 padding/boxShadow。
8. **拖动性能**：悬浮卡用 compositor 的 `translate3d` 跟随光标；拖动会话一次性创建 CSSOM 规则、一次性建立 sibling 索引映射。仅在插入槽索引发生变化时按差量更新确实位移的相邻块规则，不再每一帧替换一整个 `<style>` 文本；不直接修改 PM 管理的段落 DOM。保留原位置半透明占位、相邻块实时物理位移、单笔排序事务和 Ctrl+Z，结束自动移除所有临时规则。连续 24 次同目标区间鼠标移动的样式表 DOM Mutation 数为 0；仍需要长文档和真实触屏滑动性能实测。
