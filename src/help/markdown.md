# Markdown 与 RMD 入门

在 Recalloom 中，可以用 Markdown 编写正文，用 RMD 组件添加提示、标记、选项卡、会话和学习卡片。基础语法采用 CommonMark/GFM，数学公式使用 KaTeX。

## 从编辑器开始

- 在可视化模式中直接编辑正文，通过插入菜单添加组件。
- 打开块菜单中的“编辑块”，可以设置公式、会话、图片和其他组件的参数。
- 在源码模式中输入下方语法，也可以使用输入补全选择组件与参数。
- 修改后点击“保存”提交正文版本。预览、切换选项卡、展开内容和显示答案都是阅读操作。

文稿名称、路径和标签在文稿信息中设置。正文中的 Front Matter 会作为文字内容保留。

## 常用 Markdown

~~~~markdown
## 实验记录

**重点**、*强调*、~~删除线~~、`行内代码`。

> 引用或补充说明。

- [x] 完成实验
- [ ] 整理数据

| 参数 | 数值 |
| --- | --- |
| 电压 | 220 V |

[查看资料](https://example.com)
~~~~

代码块使用三个反引号或波浪线包围，在开头注明语言即可显示语法高亮。`mermaid` 代码块可以绘制流程图等图表。

## RMD 的三种写法

### 行内组件

将组件写在句子中，使用两组 `::` 包围。下面的例子展示状态标签和黄色标记。

~~~~rmd-example
状态是 :: badge 已完成 | success ::，请阅读 :: mark 重要结论 ::。
~~~~

### 多行容器

开始和结束标记分别独占一行，中间可以写 Markdown。组件名称后的文字通常用作标题。

~~~~rmd-example
::: info 阅读提示

这里可以写 **重点**、列表和公式。

:::
~~~~

### 独立块

独立块将目标和结束标记写在同一行，适合文稿嵌入或链接卡片。

~~~~markdown
::: embed /Projects/实验记录.md :::

::: link-card https://example.com | title=参考资料 :::
~~~~

嵌入示例中的路径需要换成知识库里实际存在的文稿路径。

## 设置参数与嵌套内容

使用两侧带空格的 ` | ` 分隔参数。可以写 `参数名=值`，也可以按组件参考中列出的顺序填写位置参数。

~~~~rmd-example
:: highlight 关键变量 | color=blue ::
~~~~

含空格或竖线的参数可以使用双引号，例如 `caption="实验装置 | 正视图"`。参数名称、可选值和默认值可在对应组件页面中查阅。

嵌套容器的外层使用更多冒号，并让每层的结束标记与开始标记保持一致。

~~~~rmd-example
:::: tabs

::: tab 概览

这是概览内容。

:::

::: tab 参数

这是参数内容。

:::

::::
~~~~

`tab` 放在 `tabs` 中，`message` 放在 `chat` 中，`definition` 放在 `glossary` 中。闪卡 `flashcard` 内按顺序放置 `front` 和 `back`。组件页面会列出具体的嵌套要求。

## 数学公式、块属性与引用

行内公式使用 `$U=IR$`。块级公式的两个 `$$` 分别独占一行。图片、表格、公式和代码可以通过 `@ attrs` 设置尺寸、说明或稳定 ID。

~~~~markdown
$$
P=UI
$$
@ attrs eq-power @

如 [[#eq-power]] 所示。
~~~~

更多公式写法见“数学公式”，跨文稿引用与嵌入见“链接与嵌入”。

## 注释与审阅

用 `%%内部备注%%` 添加注释。注释在可视化模式中显示，在预览中隐藏。多行注释的开始和结束 `%%` 分别独占一行。

CriticMarkup 可以提出新增、删除、替换和批注建议。可视化模式提供接受、拒绝与解决操作，保存后提交修改。

~~~~markdown
补充建议 {++新增文字++}
删除建议 {--待删文字--}
替换建议 {~~原文字~>新文字~~}
批注建议 {>>请核实数值<<}
~~~~

## 使用提示

- RMD 组件与 `@ attrs` 使用组件参考中列出的参数。
- 未识别或格式无效的片段会保留为原文，便于在源码模式中检查和调整。
- 代码块与公式中的符号按各自的语法解释。
- 容器最多嵌套 10 层，每层冒号围栏最多 64 个字符。

## 通过 Agent 查阅语法

Agent 可以按主题或组件读取帮助，获取与网页一致的参数说明。

~~~~json
{"topic":"markdown","component":"badge"}
~~~~

将上面的参数传给 `get_help`。使用 `kind` 选择 `inline`、`block` 或 `leaf` 写法，使用 `node` 查询 `image`、`table`、`math`、`code`、`heading` 或 `paragraph` 的块属性。
