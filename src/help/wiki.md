# WikiLink、章节引用与只读内容嵌入

Wiki 扩展由 Recalloom 的 Markdown 解析器识别，使用**稳定 UUID 或完整绝对路径**作为引用目标。不能仅凭文件名猜测身份。

## 文档链接

~~~markdown
参考 [[id:11111111-1111-4111-8111-111111111111]]。

参考路径 [[/Projects/电力系统分析/核心知识.md]]。

参考章节 [[id:11111111-1111-4111-8111-111111111111#空载试验|变压器空载试验]]。
~~~

- [[id:UUID]]：推荐形式，用稳定文档 UUID 引用。
- [[/绝对路径.md]]：使用 Recalloom 虚拟路径，不是操作系统磁盘路径。
- #章节：可选，定位 Markdown 标题。标题 `{#stable-id}` 支持显式固定锚点，改标题文字不必修改此类引用；没有固定 ID 的标题仍使用动态标题 slug。
- #^block-id：定位普通段落结尾的 `^block-id`，可用于链接或只读单段嵌入；不支持自动锚定表格单元格、列表或公式。
- |显示别名：可选，仅改变链接文字，不改变目标 UUID。
- **不支持把 [[文档名称]] 当作权威链接**。若只知道名称，先 search 或 resolve_path 并取得明确 UUID。
- 相对路径、.. 上级目录、双斜线或含不安全标记的路径不是有效引用。

## 内容嵌入

在**独立段落**中使用以下写法：

~~~markdown
{{embed:id:11111111-1111-4111-8111-111111111111}}

{{embed:id:11111111-1111-4111-8111-111111111111#空载试验}}

{{embed:/Projects/电力系统分析/核心知识.md#总结}}
~~~

嵌入是**只读展示**，不会复制或修改目标正文。支持整篇、指定标题及下属小节，也支持通过 `#^block-id` 嵌入明确标记的单个段落；不支持任务列表正文嵌入。为避免循环与超大内容，客户端限制递归嵌入深度（最多 3 层）、检测循环关系，并截断超过 50,000 字符的内容。

## 引用身份与重命名

路径引用在首次解析时会固定到目标 UUID；目标文档移动或更名后仍指向原文档，并可以提示旧路径已失效。**不能因为旧路径现在属于另一篇文档，就擅自重绑定引用。**

创建或编辑文档时自动建立 Wiki 引用关系，关系可在关联面板与知识图谱中使用。原有文档中的 Wiki 语法可能需要执行 Web 端“Wiki 引用索引补建”，但补建不应修改正文与版本历史。

## 解析边界

只有有效的普通 Markdown 正文会被解析。代码围栏、行内代码、数学公式、原始 HTML 片段、已有 Markdown 链接与图片中的相似文本，不应解析为 WikiLink；被反斜杠转义的引用不应创建关系。

与主动创建的手动关系（manage_link）不同，Wiki 引用是正文推导关系。修改正文会更新其自动引用投影。建议先解析/确认目标 UUID，再写入引用。
