# 搜索、向量索引与知识关系

Recalloom 具有元数据、字面文本、语义向量和混合检索，以及手动关系、自动 Wiki 引用、反向链接和有界知识图谱。不同来源的结果可信度与时效不同。

## 检索选择

| 需求 | 推荐模式 |
| --- | --- |
| 已知完整路径 | resolve_path |
| 精确名称/描述 | search mode=metadata |
| 刚写入的关键词或源码片段 | search mode=literal |
| 按语义寻找相关资料 | search mode=semantic |
| 综合检索 | search mode=hybrid 或 auto |
| 浏览某目录及近期内容 | browse、get_overview |
| 读取最终权威正文 | read_record、read_many |

semantic 使用 Vectorize，异步分块索引可能滞后；不可把“未检索到”视作“内容不存在”。minScore 是**原始语义相似度阈值**，Gemma 512 维默认 0.68，不适用于字面分数，也不表示答案正确概率；需要更宽泛候选时可以显式调低。搜索结果只是候选，需要继续读取正文验证。混合搜索优先精确匹配文稿自身名称、主标题；README 也可通过所在目录名称定位。摘要优先展示命中词附近的原文窗口，纯语义改写没有词面命中时回退块首。

`snippetFormat="text"` 的 `snippet` 是可读摘要，隐藏 Markdown/RMD 控制语法和链接地址，保留代码、公式表达式、表格字段、任务完成状态与删除标记的含义。它不改写原文。语义命中可返回零起始 `chunkIndex`；能够核实原文位置时还返回一起始、包含末行的 `lineStart`、`lineEnd`。使用结果的 `id`、`revision` 和行范围调用 `read_record`，其中 `maxLines=lineEnd-lineStart+1`，即可读取对应版本的原始 Markdown。历史块无法精确映射时会省略行范围；异常超长单行采取保守截取，可能保留部分语法。代码和公式里的字面 Markdown 标记会保留。

## 关系的不同类型

- 手动显式关系：由 manage_link 创建、移除，list_links 可读取。
- Wiki 自动引用：来自 Markdown [[id:UUID]]、[[/路径.md]] 与 RMD 1.0 的 ::: embed 目标 :::，不会由 manage_link 自动等价创建；其目标身份与索引见 wiki 帮助。
- 语义候选：Vectorize 根据文本相似度推荐，**不是已确认关系，不会自动保存为手动链接**。
- 同目录关系：关系图可展示同目录近邻，不能当作内容相互引用的证据。

related_records 返回已确认的入站/出站关系及可选语义候选，注意 semanticStatus。get_knowledge_graph 提供**有界图谱**：focusId 限定中心及近邻，省略时返回近期子图（最多 100 个节点），不是全库完整遍历。

关系图默认包含语义建议，可用 semantic=false 关闭。近期子图只抽样至多 6 篇已完成当前版本索引的文稿，并限制每个节点至多 4 条语义连线；没有语义边不代表文稿之间不存在相似内容。关注一篇文稿时会单独查询其语义近邻。

## 索引操作

新增或更新正文后会事务性合并索引任务，并在响应后立即后台处理。每篇文稿保留一个目标版本；失败会退避重试，Cron 每 15 分钟兜底处理遗漏和超时任务。使用 index_diagnostics 查看覆盖率、阶段、任务年龄分布与失败；index_pending 可处理有限批任务，或指定 recordId 重试一篇文稿（已完成任务需 rebuild=true）。这些操作修改索引，不编辑正文。已提交索引不代表已经验证语义查询可见。设置里的“索引”管理执行状态，“存储”展示实际容量、逻辑文本大小和向量估算；不同口径不能相加。执行记录保留 30 天用于排错；页面按需统计当前任务和容量，不保存周期性快照。

## 读取与分页

列表类结果使用 items、page；如需完整结果根据 page.nextCursor 继续。get_outline 和 read_many 可减少长文档一次性载入的开销。不要用图谱节点摘要或搜索摘录替代权威正文。
