# Recalloom

**让知识在你与 AI Agent 之间长期生长。**

Recalloom 是一款可自托管、支持版本历史的个人知识库。人可以在浏览器中阅读、编辑和整理内容，AI Agent 则通过授权接口检索与维护同一份知识。无论是研究笔记、项目文档还是长期任务，内容都属于你，也不会因为对话结束而失去延续性。

## 为什么选择 Recalloom？

| 能力 | 你能做什么 |
| --- | --- |
| **人机协同** | 浏览器与 AI Agent 共用知识、目录和历史；不同客户端可以持续接手同一项目 |
| **自由组织** | 使用多级文件夹、标签、目录概览和文档大纲管理长期资料 |
| **更强的 Markdown** | 可视化、源码和只读预览自由切换；支持公式、扩展组件、批注与交互式内容 |
| **找到真正需要的内容** | 通过关键词、语义检索、筛选与关联记录重新发现知识 |
| **看见知识之间的联系** | 在关系图中探索文档、反向链接与相似内容，并自主确认关联 |
| **放心修改** | 版本追踪、差异比较、冲突保护和历史恢复，让多人或多 Agent 协作更可控 |
| **长期可维护** | 归档、备份、恢复和可分别授予读写权限的授权连接 |

### 面向日常使用，也面向长期协作

**写作与阅读** — 在熟悉的文档界面中直接编辑内容，使用 RMD 的 Callout、图表式组件、数学公式、代码块、链接卡片等表达想法。不同视图共享同一份 Markdown 内容。

**检索与关联** — 不需要提前记住文件位置。可以从目录、标签、搜索或关系网重新进入一个主题，将孤立笔记连接成可探索的知识结构。

**与 Agent 共享上下文** — 授权 Agent 读取已有记录、查询版本、更新项目说明或维护任务。读写权限独立管理，修改可审计且可以恢复。

## 部署

Recalloom 运行在你自己的 **Cloudflare** 账户中。部署前需要创建 Workers、D1、KV、Vectorize 资源，并配置授权密钥。完整的配置、资源绑定和自动部署步骤见 [部署指南](docs/deployment.md)。

**快速开始：**

1. 准备 Node.js 24 与 pnpm 11，克隆仓库并执行 `pnpm install`。
2. 登录 Cloudflare，按部署指南创建并绑定所需资源。
3. 在 Cloudflare Workers Builds 中连接本仓库，将生产分支设为 `main`，并按指南配置构建变量和 Secrets。
4. 部署后通过 Web 控制台登录，或在支持 OAuth 的 MCP 客户端中连接你的服务地址。

需要本地构建和自定义部署时，使用 [部署指南](docs/deployment.md) 中的完整命令。正式部署前请妥善保护授权密钥，并在首次启用前检查资源绑定是否正确。
